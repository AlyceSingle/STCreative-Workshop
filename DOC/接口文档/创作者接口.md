# 创作者接口

> 所有创作者接口均需要用户登录认证

---

## 1. 创作者状态

### 1.1 获取创作者状态

#### 1.1.1 基本信息

> 请求路径：/api/creator/status  
> 请求方式：GET  
> 接口描述：获取当前用户的角色和创作者申请状态

#### 1.1.2 请求参数

无

#### 1.1.3 响应数据

参数格式：application/json

普通用户（无申请记录）：
```json
{
  "role": "user",
  "application": null
}
```

已有申请记录：
```json
{
  "role": "user",
  "application": {
    "status": "pending",
    "reason": "我想成为创作者...",
    "platform": "类脑",
    "published_works": "作品A、作品B",
    "admin_note": "",
    "applied_at": "2024-01-10T10:30:00",
    "reviewed_at": null
  }
}
```

已是创作者：
```json
{
  "role": "creator",
  "application": null
}
```

## 2. 创作者申请

### 2.1 提交创作者申请

#### 2.1.1 基本信息

> 请求路径：/api/creator/apply  
> 请求方式：POST  
> 接口描述：提交创作者申请，等待管理员审核

#### 2.1.2 请求参数

参数格式：application/json

| 参数名         | 类型   | 是否必须 | 备注                                       |
|----------------|--------|----------|--------------------------------------------|
| reason         | string | 是       | 申请理由，5-500 字                         |
| platform       | string | 是       | 发布平台：类脑、旅程、其他平台             |
| published_works| string | 是       | 已发布作品名称或链接，2-1000 字            |

请求参数样例：
```json
{
  "reason": "我希望成为创作者，已经发布了多个高质量的角色卡和世界书作品",
  "platform": "类脑",
  "published_works": "《蒸汽朋克冒险家》、《赛博朋克侦探》等角色卡作品"
}
```

#### 2.1.3 响应数据

参数格式：application/json

成功：
```json
{
  "ok": true,
  "message": "申请已提交，请等待管理员审核"
}
```

失败情况：

已是创作者或管理员：
```json
{
  "error": "你已经是创作者或管理员"
}
```

已有待审核申请：
```json
{
  "error": "你已有一条待审核的申请，请耐心等待"
}
```

申请理由过短：
```json
{
  "error": "请填写至少 5 个字的申请理由"
}
```

申请理由过长：
```json
{
  "error": "申请理由不能超过 500 字"
}
```

平台无效：
```json
{
  "error": "请选择有效的发布平台（类脑/旅程/其他平台）"
}
```

作品信息过短：
```json
{
  "error": "请填写至少一个已发布作品名称或链接"
}
```

作品信息过长：
```json
{
  "error": "已发布作品信息不能超过 1000 字"
}
```
