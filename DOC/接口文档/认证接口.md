# 认证接口

## 1. Discord OAuth2 授权

### 1.1 发起 Discord 授权

#### 1.1.1 基本信息

> 请求路径：/auth/discord  
> 请求方式：GET  
> 接口描述：发起 Discord OAuth2 授权流程，支持弹窗模式和 JWT 模式

#### 1.1.2 请求参数

参数格式：查询参数

| 参数名  | 类型   | 是否必须 | 备注                                         |
| ------- | ------ | -------- | -------------------------------------------- |
| popup   | string | 否       | 设为 '1' 启用弹窗模式                        |
| authKey | string | 否       | JWT 模式下的认证密钥，用于后续轮询获取 token |

请求参数样例：
```
/auth/discord?popup=1
/auth/discord?authKey=abc123xyz
```

#### 1.1.3 响应数据

参数格式：重定向

- 弹窗模式：重定向到前端的 `/oauth-callback` 页面
- JWT 模式：返回自动关闭的 HTML 页面
- 传统模式：重定向到前端首页

## 2. Discord OAuth2 回调

### 2.1 授权回调

#### 2.1.1 基本信息

> 请求路径：/auth/discord/callback  
> 请求方式：GET  
> 接口描述：Discord OAuth2 授权完成后的回调接口，由 Discord 自动调用

#### 2.1.2 响应数据

参数格式：重定向

成功时：
- 弹窗模式：重定向到 `{FRONTEND_URL}/oauth-callback?success=1`
- 传统模式：重定向到 `{FRONTEND_URL}`

失败时：
- 弹窗模式：重定向到 `{FRONTEND_URL}/oauth-callback?success=0`
- 传统模式：重定向到 `{FRONTEND_URL}?login=failed`

## 3. 获取当前用户信息

### 3.1 查询当前登录用户

#### 3.1.1 基本信息

> 请求路径：/auth/me  
> 请求方式：GET  
> 接口描述：获取当前登录用户的详细信息，支持 JWT Token 和 Session Cookie 两种认证方式

#### 3.1.2 请求参数

参数格式：请求头

| 参数名        | 类型   | 是否必须 | 备注                             |
| ------------- | ------ | -------- | -------------------------------- |
| Authorization | string | 否       | Bearer Token 格式，用于 JWT 认证 |

请求头样例：
```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

#### 3.1.3 响应数据

参数格式：application/json

成功响应：
```json
{
  "id": 1,
  "discord_id": "123456789012345678",
  "username": "example_user",
  "display_name": "显示名称",
  "avatar": "https://cdn.discordapp.com/avatars/123456789012345678/abcdef123456.png",
  "role": "user",
  "created_at": "2024-01-10T10:30:00"
}
```

未登录响应：
```json
null
```

## 4. 轮询获取 JWT Token

### 4.1 轮询获取认证令牌

#### 4.1.1 基本信息

> 请求路径：/auth/poll  
> 请求方式：GET  
> 接口描述：在 JWT 模式下，前端通过轮询此接口获取 OAuth 完成后的 token

#### 4.1.2 请求参数

参数格式：查询参数

| 参数名 | 类型   | 是否必须 | 备注                 |
| ------ | ------ | -------- | -------------------- |
| key    | string | 是       | 授权时传入的 authKey |

请求参数样例：
```
/auth/poll?key=abc123xyz
```

#### 4.1.3 响应数据

参数格式：application/json

Token 已就绪：
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "discord_id": "123456789012345678",
    "username": "example_user",
    "display_name": "显示名称",
    "avatar": "https://cdn.discordapp.com/avatars/123456789012345678/abcdef123456.png",
    "role": "user",
    "created_at": "2024-01-10T10:30:00"
  }
}
```

Token 未就绪或已过期：
```json
{
  "token": null,
  "user": null
}
```

错误响应：
```json
{
  "error": "缺少 key 参数"
}
```

## 5. 登出

### 5.1 用户登出

#### 5.1.1 基本信息

> 请求路径：/auth/logout  
> 请求方式：POST  
> 接口描述：用户登出，销毁 session 并清除 cookie

#### 5.1.2 请求参数

无

#### 5.1.3 响应数据

参数格式：application/json

```json
{
  "ok": true
}
```
