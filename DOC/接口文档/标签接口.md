# 标签接口

---

## 1. 标签列表

### 1.1 获取所有标签

#### 1.1.1 基本信息

> 请求路径：/api/tags  
> 请求方式：GET  
> 接口描述：获取所有标签及其使用次数，按使用次数降序排列

#### 1.1.2 请求参数

无

#### 1.1.3 响应数据

参数格式：application/json

```json
[
  {
    "name": "冒险",
    "count": 25
  },
  {
    "name": "蒸汽朋克",
    "count": 18
  },
  {
    "name": "奇幻",
    "count": 15
  },
  {
    "name": "科幻",
    "count": 10
  },
  {
    "name": "悬疑",
    "count": 5
  }
]
```

#### 1.1.4 字段说明

| 字段名 | 类型    | 说明                     |
|--------|---------|--------------------------|
| name   | string  | 标签名称                 |
| count  | integer | 该标签被故事使用的次数   |
