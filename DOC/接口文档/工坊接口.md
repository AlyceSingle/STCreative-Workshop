# 工坊接口

---

## 1. 工坊管理

### 1.1 获取工坊列表

#### 1.1.1 基本信息

> 请求路径：/api/workshop/workshops  
> 请求方式：GET  
> 接口描述：获取所有已激活的工坊列表

#### 1.1.2 请求参数

无

#### 1.1.3 响应数据

参数格式：application/json

```json
{
  "data": [
    {
      "id": 1,
      "name": "蒸汽朋克世界",
      "slug": "steampunk_world_1704067200000",
      "description": "蒸汽朋克风格的世界书工坊",
      "worldbook": "steampunk_worldbook",
      "author_id": 1,
      "status": "active",
      "created_at": "2024-01-10T10:30:00"
    }
  ]
}
```

---

### 1.2 创建工坊

#### 1.2.1 基本信息

> 请求路径：/api/workshop/workshops  
> 请求方式：POST  
> 接口描述：创建新工坊，仅创作者或管理员可调用

#### 1.2.2 请求参数

参数格式：application/json

| 参数名      | 类型   | 是否必须 | 备注               |
|-------------|--------|----------|--------------------|
| name        | string | 是       | 工坊名称，最多 50 字 |
| description | string | 否       | 工坊描述           |
| worldbook   | string | 否       | 默认世界书名称     |

请求参数样例：
```json
{
  "name": "蒸汽朋克世界",
  "description": "蒸汽朋克风格的世界书工坊",
  "worldbook": "steampunk_worldbook"
}
```

#### 1.2.3 响应数据

参数格式：application/json

成功（HTTP 201）：
```json
{
  "data": {
    "id": 1,
    "name": "蒸汽朋克世界",
    "slug": "steampunk_world_1704067200000",
    "description": "蒸汽朋克风格的世界书工坊",
    "worldbook": "steampunk_worldbook",
    "author_id": 1,
    "status": "active",
    "created_at": "2024-01-10T10:30:00"
  },
  "message": "工坊创建成功"
}
```

创作者创建时（需审核）：
```json
{
  "data": { ... },
  "message": "工坊申请已提交，等待管理员审批"
}
```

失败：
```json
{
  "error": "只有创作者或管理员才能创建工坊"
}
```
```json
{
  "error": "工坊名称不能为空"
}
```
```json
{
  "error": "工坊名称不能超过 50 字"
}
```

## 2. 模组管理

### 2.1 获取模组列表

#### 2.1.1 基本信息

> 请求路径：/api/workshop  
> 请求方式：GET  
> 接口描述：分页获取模组列表，支持多种筛选条件

#### 2.1.2 请求参数

参数格式：查询参数

| 参数名     | 类型    | 是否必须 | 备注                                       |
|------------|---------|----------|--------------------------------------------|
| page       | integer | 否       | 页码，默认 1                               |
| limit      | integer | 否       | 每页条数，默认 20，最大 50                 |
| workshop   | string  | 否       | 按工坊 slug 筛选（兼容旧参数 section）     |
| section    | string  | 否       | 同 workshop，兼容旧参数                    |
| q          | string  | 否       | 按模组标题搜索                             |
| tag        | string  | 否       | 按标签筛选                                 |
| author_id  | integer | 否       | 按作者 ID 筛选                             |
| sort       | string  | 否       | 排序方式：popular(热度，默认)、newest(最新) |

请求参数样例：
```
/api/workshop?page=1&limit=20&workshop=steampunk&tag=冒险&sort=newest
```

## 5. 条目管理

### 5.1 创建条目

#### 5.1.1 基本信息

> 请求路径：/api/workshop/packs/:packId/entries  
> 请求方式：POST  
> 接口描述：在模组中创建新条目，需要用户登录且为模组作者或管理员

#### 5.1.2 请求参数

参数格式：路径参数 + application/json

路径参数：

| 参数名 | 类型    | 是否必须 | 备注    |
|--------|---------|----------|---------|
| packId | integer | 是       | 模组 ID |

请求体：

| 参数名                      | 类型     | 是否必须 | 备注                                          |
|-----------------------------|----------|----------|-----------------------------------------------|
| name                        | string   | 是       | 条目名称，最多 200 字                         |
| entry_type                  | string   | 否       | 条目类型，默认 worldbook                      |
| extra_data                  | object   | 否       | 额外数据，默认 {}                             |
| enabled                     | boolean  | 否       | 是否启用，默认 true                           |
| content                     | string   | 否       | 条目内容                                      |
| strategy_type               | string   | 否       | 策略类型：constant、selective，默认 selective |
| keys                        | string[] | 否       | 主关键词数组                                  |
| keys_secondary_logic        | string   | 否       | 次关键词逻辑：and_any、not_all、not_any、and_all，默认 and_any |
| keys_secondary              | string[] | 否       | 次关键词数组                                  |
| scan_depth                  | string   | 否       | 扫描深度，默认 same_as_global                 |
| position_type               | string   | 否       | 位置类型，默认 after_character_definition     |
| position_order              | integer  | 否       | 位置顺序，默认 100                            |
| position_depth              | integer  | 否       | 位置深度，默认 4                              |
| position_role               | string   | 否       | 位置角色：system、user、assistant，默认 system |
| probability                 | integer  | 否       | 触发概率 0-100，默认 100                      |
| recursion_prevent_incoming  | boolean  | 否       | 防止递归进入，默认 false                      |
| recursion_prevent_outgoing  | boolean  | 否       | 防止递归输出，默认 false                      |
| recursion_delay_until       | integer  | 否       | 递归延迟                                      |
| effect_sticky               | integer  | 否       | 粘性效果                                      |
| effect_cooldown             | integer  | 否       | 冷却时间                                      |
| effect_delay                | integer  | 否       | 延迟效果                                      |

请求参数样例：
```json
{
  "name": "机械师艾拉",
  "entry_type": "worldbook",
  "enabled": true,
  "content": "艾拉是一位天才机械师，擅长修理各种蒸汽机械...",
  "strategy_type": "selective",
  "keys": ["艾拉", "机械师", "工程师"],
  "keys_secondary_logic": "and_any",
  "keys_secondary": [],
  "scan_depth": "same_as_global",
  "position_type": "after_character_definition",
  "position_order": 100,
  "position_depth": 4,
  "position_role": "system",
  "probability": 100,
  "recursion_prevent_incoming": false,
  "recursion_prevent_outgoing": false
}
```

#### 5.1.3 响应数据

参数格式：application/json

成功（HTTP 201）：
```json
{
  "data": {
    "id": 1
  },
  "message": "条目添加成功"
}
```

失败：
```json
{
  "error": "无效的模组 ID"
}
```
```json
{
  "error": "模组不存在"
}
```

## 6. 枚举值说明

### 6.1 策略类型 (strategy_type)

| 值        | 说明     |
|-----------|----------|
| constant  | 常量触发 |
| selective | 选择性触发（根据关键词） |

### 6.2 位置类型 (position_type)

| 值                          | 说明                   |
|-----------------------------|------------------------|
| before_character_definition | 角色定义之前           |
| after_character_definition  | 角色定义之后           |
| before_example_messages     | 示例消息之前           |
| after_example_messages      | 示例消息之后           |
| before_author_note          | 作者备注之前           |
| after_author_note           | 作者备注之后           |
| at_depth                    | 在指定深度             |

### 6.3 次关键词逻辑 (keys_secondary_logic)

| 值       | 说明               |
|----------|--------------------|
| and_any  | 满足任意一个即可   |
| not_all  | 不满足全部         |
| not_any  | 不满足任意一个     |
| and_all  | 必须满足全部       |

### 6.4 位置角色 (position_role)

| 值       | 说明     |
|----------|----------|
| system   | 系统角色 |
| user     | 用户角色 |
| assistant| 助手角色 |
