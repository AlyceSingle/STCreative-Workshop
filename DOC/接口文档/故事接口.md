# 故事接口

---

## 1. 故事列表

### 1.1 获取故事列表

#### 1.1.1 基本信息

> 请求路径：/api/stories  
> 请求方式：GET  
> 接口描述：分页获取故事列表，支持标签过滤

#### 1.1.2 请求参数

参数格式：查询参数

| 参数名 | 类型    | 是否必须 | 备注                       |
| ------ | ------- | -------- | -------------------------- |
| page   | integer | 否       | 页码，默认 1               |
| limit  | integer | 否       | 每页条数，默认 12，最大 50 |
| tag    | string  | 否       | 按标签筛选                 |

请求参数样例：
```
/api/stories?page=1&limit=12&tag=冒险
```

#### 1.1.3 响应数据

参数格式：application/json

```json
{
  "stories": [
    {
      "id": 1,
      "title": "蒸汽朋克冒险",
      "preview": "在一个充满蒸汽机械的世界里，年轻的工程师艾拉发现了一个古老的秘密...",
      "created_at": "2024-01-10T10:30:00",
      "tags": ["冒险", "蒸汽朋克", "奇幻"],
      "author": {
        "id": 1,
        "username": "story_writer",
        "avatar": "https://cdn.discordapp.com/avatars/123456789012345678/abcdef123456.png"
      }
    }
  ],
  "pagination": {
    "total": 100,
    "page": 1,
    "limit": 12,
    "totalPages": 9
  }
}
```

## 2. 故事详情

### 2.1 获取故事详情

#### 2.1.1 基本信息

> 请求路径：/api/stories/:id  
> 请求方式：GET  
> 接口描述：获取单篇故事的完整内容

#### 2.1.2 请求参数

参数格式：路径参数

| 参数名 | 类型    | 是否必须 | 备注    |
| ------ | ------- | -------- | ------- |
| id     | integer | 是       | 故事 ID |

#### 2.1.3 响应数据

参数格式：application/json

成功：
```json
{
  "id": 1,
  "title": "蒸汽朋克冒险",
  "content": "# 蒸汽朋克冒险\n\n在一个充满蒸汽机械的世界里...",
  "created_at": "2024-01-10T10:30:00",
  "tags": ["冒险", "蒸汽朋克", "奇幻"],
  "author": {
    "id": 1,
    "username": "story_writer",
    "avatar": "https://cdn.discordapp.com/avatars/123456789012345678/abcdef123456.png"
  }
}
```

失败：
```json
{
  "error": "无效的故事 ID"
}
```
```json
{
  "error": "故事不存在"
}
```

## 3. 创建故事

### 3.1 发布新故事

#### 3.1.1 基本信息

> 请求路径：/api/stories  
> 请求方式：POST  
> 接口描述：发布新故事，需要用户登录

#### 3.1.2 请求参数

参数格式：application/json

| 参数名  | 类型     | 是否必须 | 备注                     |
| ------- | -------- | -------- | ------------------------ |
| title   | string   | 是       | 故事标题，最多 200 字    |
| content | string   | 是       | 故事内容，支持 Markdown  |
| tags    | string[] | 否       | 标签数组，最多 10 个标签 |

请求参数样例：
```json
{
  "title": "蒸汽朋克冒险",
  "content": "# 蒸汽朋克冒险\n\n在一个充满蒸汽机械的世界里，年轻的工程师艾拉发现了一个古老的秘密...",
  "tags": ["冒险", "蒸汽朋克", "奇幻"]
}
```

#### 3.1.3 响应数据

参数格式：application/json

成功（HTTP 201）：
```json
{
  "id": 1,
  "message": "故事发布成功"
}
```

失败：
```json
{
  "error": "标题不能为空"
}
```
```json
{
  "error": "内容不能为空"
}
```
```json
{
  "error": "标题不能超过 200 字"
}
```

## 4. 删除故事

### 4.1 删除故事

#### 4.1.1 基本信息

> 请求路径：/api/stories/:id  
> 请求方式：DELETE  
> 接口描述：删除故事，仅作者本人可删除

#### 4.1.2 请求参数

参数格式：路径参数

| 参数名 | 类型    | 是否必须 | 备注    |
| ------ | ------- | -------- | ------- |
| id     | integer | 是       | 故事 ID |

#### 4.1.3 响应数据

参数格式：application/json

成功：
```json
{
  "success": true,
  "message": "故事已删除"
}
```

失败：
```json
{
  "error": "无效的故事 ID"
}
```
```json
{
  "error": "故事不存在"
}
```
```json
{
  "error": "无权删除此故事"
}
```
